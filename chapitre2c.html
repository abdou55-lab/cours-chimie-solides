7. Occupation dans les Structures Métalliques et Ioniques
7.1 Structures Métalliques

Les métaux cristallisent généralement selon trois structures principales :

7.1.1 Structure Cubique Compacte (CCP ou F)
  • Empilement : ABC ABC...
  • Exemples : Cu, Al, Au, Pt, Ni, Ag
  • Coordinence : 12
  • Fraction de remplissage : 74,05%
7.1.2 Structure Hexagonale Compacte (HCP)
  • Empilement : AB AB...
  • Exemples : Mg, Zn, Ti, Co, Zr
  • Coordinence : 12
  • Fraction de remplissage : 74,05%
7.1.3 Structure Cubique Centrée (CC ou I)
  • Empilement : Non compact
  • Exemples : Fe (α), Cr, Mo, W, Na, K
  • Coordinence : 8
  • Fraction de remplissage : 68,02%
7.2 Structures Ioniques

Les structures ioniques sont souvent décrites comme des empilements d'ions de grand rayon (anions) dans lesquels les cations viennent occuper des sites interstitiels.

7.2.1 Structure NaCl (Type Roches salines)
  • Réseau : Cubique F (pour chaque type d'ion)
  • Description : Empilement CCP de Cl− avec tous les sites octaédriques occupés par Na+
  • Coordinence : 6 (chaque ion est entouré de 6 ions de l'autre type)
  • Exemples : NaCl, KCl, LiF, MgO, CaO
7.2.2 Structure CsCl
  • Réseau : Cubique P (pour chaque type d'ion, décalé de 1/2)
  • Description : Cubique simple de Cl− avec des Cs+ au centre des cubes
  • Coordinence : 8 (chaque ion est entouré de 8 ions de l'autre type)
  • Exemples : CsCl, CsBr, CsI, NH4Cl
7.2.3 Structure Fluorine (CaF2)
  • Réseau : Cubique F pour Ca2+
  • Description : Empilement CCP de Ca2+ avec tous les sites tétraédriques occupés par F−
  • Coordinence : Ca2+ : 8, F− : 4
  • Exemples : CaF2, BaF2, SrF2, UO2, CeO2
8. Outils Informatiques et IA pour la Cristallographie
8.1 Logiciels de Visualisation et de Simulation
  • VESTA : Visualisation de structures cristallines et de densité électronique.
  • Materials Studio : Suite complète pour la modélisation et la simulation en science des matériaux.
  • Quantum ESPRESSO : Code open-source pour les calculs de structure électronique basé sur la DFT.
  • Atomsk : Outil de construction et de manipulation de structures cristallines.
  • Ovito : Visualisation et analyse de données de simulation atomistique.
  • CCP14 : Collection de logiciels de cristallographie disponibles gratuitement.
8.2 Bases de Données Cristallographiques
  • Crystallography Open Database (COD) : Base de données libre de structures cristallines.
  • Inorganic Crystal Structure Database (ICSD) : Base de données de structures cristallines inorganiques.
  • Cambridge Structural Database (CSD) : Base de données de structures organiques et organométalliques.
  • Materials Project : Base de données de matériaux avec propriétés calculées.
  • AFLOW : Base de données automatisée de structures et propriétés.
8.3 Outils d'Intelligence Artificielle
  • AlphaFold : Prédiction de structures protéiques par IA (DeepMind).
  • CGCNN : Réseau de neurones graphiques pour la prédiction de propriétés cristallines.
  • SchNetPack : Paquetage pour les réseaux de neurones en chimie quantique et science des matériaux.
  • Materials Project Dashboard : Plateforme avec intégration d'outils d'analyse par IA.
  • Materials Cloud : Plateforme pour la science des matériaux basée sur les données et l'IA.
8.4 Ressources Éducatives et Tutoriels
  • DoITPoMS : Tutoriels en ligne sur la science des matériaux et la cristallographie.
  • NanoHUB : Ressources éducatives et outils de simulation en nanotechnologie.
  • International Union of Crystallography (IUCr) : Ressources et publications en cristallographie.
  • Crystal Symmetry : Blog éducatif sur la symétrie cristalline.

📝 Conclusion du chapitre 2

Ce chapitre a introduit les concepts fondamentaux de la cristallographie : les réseaux de Bravais, les mailles élémentaires (primitive et conventionnelle), les 7 systèmes cristallins et les 14 réseaux de Bravais. Nous avons également vu comment les sites interstitiels (octaédriques et tétraédriques) sont occupés dans les structures métalliques et ioniques. La maîtrise de ces concepts est essentielle pour comprendre les propriétés physico-chimiques des matériaux solides. Les outils informatiques et d'IA présentés (VESTA, Materials Project, CGCNN, etc.) offrent des possibilités puissantes pour la modélisation et la découverte de nouveaux matériaux.
