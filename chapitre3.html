Chapitre 3 — Structures Cristallines Courantes

Empilements compacts, structures ioniques et matériaux fonctionnels

👨‍🏫 Abdeldaker LEBOUKH • 📅 Année universitaire 2026-2027

1. Introduction

Ce chapitre présente les structures cristallines les plus courantes rencontrées dans les matériaux solides. Nous aborderons les empilements compacts, les structures ioniques typiques, ainsi que des exemples de matériaux fonctionnels.

2. Empilements Compacts

Les empilements compacts sont des arrangements d'atomes ou de sphères qui maximisent la densité de l'espace occupé. Ils sont à la base de nombreuses structures métalliques.

2.1 Principe des empilements compacts

Dans un empilement compact, les sphères sont arrangées de manière à occuper le maximum d'espace. La compacité maximale est de 74 % pour les structures CFC et HC.

2.2 Cubique à Faces Centrées (CFC)

La structure CFC est un empilement compact de type ABCABC. Les atomes occupent les sommets et les centres des faces du cube.

  • Coordinence : 12
  • Nombre d'atomes par maille : 4
  • Compacité : 74 %
  • Exemples : Cu, Al, Au, Ag, Ni

2.3 Hexagonal Compact (HC)

La structure HC est un empilement compact de type ABAB. Les atomes occupent les sommets d'un prisme hexagonal.

  • Coordinence : 12
  • Nombre d'atomes par maille : 6
  • Compacité : 74 %
  • Exemples : Mg, Zn, Ti, Co
💡 À retenir : CFC et HC ont la même compacité (74 %) mais des empilements différents (ABCABC vs ABAB).

2.4 Compacité, Densité et Coordinence

2.4.1 Compacité (C)

C = (Volume occupé par les atomes) / (Volume total de la maille)
  • CFC : C = 74 %
  • HC : C = 74 %
  • Cubique Centré (CC) : C = 68 %
  • Cubique Simple (CS) : C = 52 %

2.4.2 Densité théorique (ρ)

ρ = (n × M) / (NA × Vmaille)

où n est le nombre d'atomes par maille, M la masse molaire, NA la constante d'Avogadro et Vmaille le volume de la maille.

2.4.3 Coordinence

  • CFC : 12 (voisins les plus proches)
  • HC : 12
  • CC : 8
  • CS : 6

3. Structures Types Ioniques

Les structures ioniques sont formées par l'assemblage d'ions de charges opposées. La structure dépend du rapport des rayons ioniques.

3.1 Structure NaCl (Cubique F)

  • Description : Ions Cl⁻ en CFC, ions Na⁺ dans tous les sites octaédriques
  • Coordinence : Na⁺ : 6, Cl⁻ : 6
  • Exemples : NaCl, KCl, MgO, CaO

3.2 Structure CsCl (Cubique P)

  • Description : Ions Cl⁻ en cubique simple, ions Cs⁺ au centre du cube
  • Coordinence : Cs⁺ : 8, Cl⁻ : 8
  • Exemples : CsCl, CsBr, CsI

3.3 Structure ZnS (Blende et Wurtzite)

3.3.1 Structure Blende (Sphalerite)

  • Description : Ions S²⁻ en CFC, ions Zn²⁺ dans la moitié des sites tétraédriques
  • Coordinence : Zn²⁺ : 4, S²⁻ : 4
  • Exemples : ZnS, GaAs, InP, CdTe

3.3.2 Structure Wurtzite

  • Description : Ions S²⁻ en HC, ions Zn²⁺ dans la moitié des sites tétraédriques
  • Coordinence : Zn²⁺ : 4, S²⁻ : 4
  • Exemples : ZnS (hexagonal), GaN, ZnO, AlN
📌 Note : La blende et la wurtzite sont des polymorphes du ZnS (même composition chimique, structures différentes).

3.4 Structure CaF₂ (Fluorine)

  • Description : Ions Ca²⁺ en CFC, ions F⁻ dans tous les sites tétraédriques
  • Coordinence : Ca²⁺ : 8, F⁻ : 4
  • Exemples : CaF₂, SrF₂, BaF₂, UO₂

3.5 Structure TiO₂ (Rutile, Anatase, Brookite)

  • Rutile : Structure tétragonale, la plus stable
  • Anatase : Structure tétragonale, utilisée en photocatalyse
  • Brookite : Structure orthorhombique, rare
  • Exemples : TiO₂ (pigment blanc, photocatalyseur)

3.6 Structure Pérovskite (CaTiO₃)

  • Description : Structure cubique ou tétragonale avec des octaèdres TiO₆
  • Exemples : CaTiO₃, BaTiO₃, SrTiO₃, PbTiO₃
  • Propriétés : Ferroélectricité, piézoélectricité, supraconductivité
💡 À retenir : La structure pérovskite est l'une des plus importantes en sciences des matériaux.

3.7 Structure Spinelle (MgAl₂O₄) et Anti-Spinelle

  • Spinelle normal : A²⁺ en sites tétraédriques, B³⁺ en sites octaédriques
  • Anti-spinelle : A²⁺ en sites octaédriques, B³⁺ en sites tétraédriques et octaédriques
  • Exemples : MgAl₂O₄, Fe₃O₄ (inverse), CoFe₂O₄

4. Exemples de Matériaux Fonctionnels

4.1 Oxydes Conducteurs Transparents (ITO, LiCoO₂)

  • ITO (Sn:In₂O₃) : Utilisé dans les écrans tactiles, les cellules solaires
  • LiCoO₂ : Électrode positive dans les batteries lithium-ion

4.2 Superconducteurs (YBa₂Cu₃O₇)

  • YBCO (YBa₂Cu₃O₇) : Supraconducteur à haute température critique (Tc ≈ 93 K)
  • Structure : Pérovskite déformée avec des plans CuO₂

4.3 Matériaux Magnétiques (Fe₃O₄)

  • Magnétite (Fe₃O₄) : Structure spinelle inverse, ferrimagnétique
  • Applications : Enregistrement magnétique, nanoparticules médicales

5. Outils Informatiques pour l'Analyse des Structures Cristallines

5.1 Visualisation 3D

  • VESTA : Logiciel gratuit de visualisation de structures
  • VMD : Visualisation moléculaire et cristalline
  • Mercury : Interface pour la visualisation de structures cristallines

5.2 Simulation et Calculs

  • DFT (Density Functional Theory) : Calculs ab initio
  • VASP, Quantum ESPRESSO : Logiciels de calcul DFT

5.3 Bases de Données

  • ICSD (Inorganic Crystal Structure Database)
  • COD (Crystallography Open Database)
  • Materials Project
